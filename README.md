
# ربات روبیکا چندمنظوره و مدیریت گروه

این پروژه یک ربات روبیکا است که برای مدیریت گروه‌های روبیکا، سرگرمی، آموزش، سیستم XP، بازی، و تعامل با کاربران طراحی شده است. ساختار آن چندلایه و ماژولار است و از یک پل وب‌هوک PHP برای دریافت آپدیت‌ها و یک اسکریپت Python برای پردازش و اجرای منطق ربات استفاده می‌کند.

## خلاصه‌ی سریع

- مدیریت پیشرفته‌ی گروه
- سیستم سطح، تجربه و نشان
- سامانه‌ی اخطار و سکوت self-managed
- بازی‌های تعاملی و سرگرمی‌های روزانه
- پاسخ‌گویی با هوش مصنوعی
- ذخیره‌سازی داده‌ها در SQLite
- پشتیبانی از وب‌هوک با PHP

## امکانات اصلی

### 1) مدیریت گروه
این ربات قابلیت‌های متنوعی برای کنترل گروه دارد، از جمله:

- قفل گروه
- ضدلینک
- ضدتبلیغ
- ضدفحش
- ضدهنگی
- ضدایموجی
- ضدویرایش
- ضدمنشن
- ضدگیف
- سکوت و اخراج کاربر
- تنظیم پیام خوش‌آمد و خداحافظی
- کپچا برای جلوگیری از ورود ربات‌ها و کاربران ناشناس
- دستورات سفارشی برای هر گروه

### 2) سیستم سطح و تجربه
کاربران می‌توانند با فعالیت در گروه، تجربه کسب کنند و سطح خود را افزایش دهند.

ویژگی‌های مهم:

- افزایش XP بر اساس فعالیت
- سطح‌دهی خودکار
- اهدای نشان‌های ویژه برای سطوح خاص
- نمایش لیدربورد برترین کاربران

### 3) سرگرمی و بازی
ربات شامل چندین ماژول سرگرمی و بازی است، از جمله:

- بازی ریاضی
- بازی کلمات
- بازی حدس عدد
- فال حافظ
- فال روز
- لطیفه
- حقیقت جالب
- معما و جواب معما
- داستان و خاطره
- حدیث و چالش روزانه
- تست شخصیت
- طالع‌بینی ماه تولد
- سن شمسی و اطلاعات تولد

### 4) ابزارهای کاربردی
برخی از قابلیت‌های کاربردی پروژه عبارت‌اند از:

- محاسبه سن
- اطلاعات قبله و رمضان
- تبدیل فونت
- نمایش نرخ ارز و قیمت ارز دیجیتال
- تحلیل احساسات و اطلاعات متفرقه
- دستورات آموزشی و یادگیری سفارشی

### 5) هوش مصنوعی
از طریق دستورهای مانند `+سوال` می‌توان از مدل هوش مصنوعی سوال پرسید. این بخش در فایل مربوط به پردازش دستورات AI پیاده‌سازی شده و برای پاسخ‌گویی به کاربر استفاده می‌شود.

## معماری پروژه

این پروژه از چند ماژول اصلی تشکیل شده است:

- `main.py`: نقطه‌ی ورود اصلی برنامه و اجرای تسک‌های پس‌زمینه
- `handler.py`: پردازش دستورات کاربر، دستورات عمومی و مدیریت گروه
- `manager.py`: منطق مدیریتی، قوانین گروه، سکوت، اخطار، کپچا و رویدادهای مرتبط
- `utils.py`: توابع مشترک، دیتابیس، قوانین، فیلترها، ابزارهای کمکی و پردازش متن
- `database.py`: عملیات دیتابیس و توابع مربوط به XP، آمار، اخطار، دستورات سفارشی
- `state.py`: نگهداری حالت در حافظه و ساخت جداول پیشرفته‌ی دیتابیس
- `ai_assistant.py`: پردازش دستورات مربوط به هوش مصنوعی
- `fun.py` و `games.py`: منطق سرگرمی و بازی‌ها
- `index.php`: دریافت webhook از سرور و ذخیره‌ی داده‌ها در `message.json`

## جریان کار

1. درخواست‌های روبیکا از طریق وب‌هوک به PHP رسید می‌کنند.
2. فایل `index.php` داده را دریافت و در `message.json` ذخیره می‌کند.
3. اسکریپت Python از فایل `message.json` یا از رویدادهای دریافت‌شده، داده را پردازش می‌کند.
4. منطق ربات در `handler.py` و `manager.py` اجرا می‌شود.
5. اطلاعات در SQLite و فایل‌های JSON ذخیره می‌شود.

## پیش‌نیازها

- Python 3.10 یا بالاتر
- کتابخانه‌های مشخص‌شده در `requirements.txt`
- دسترسی به سرور وب برای وب‌هوک PHP (در صورت استفاده از حالت webhook)
- توکن ربات روبیکا و تنظیم آدرس وب‌هوک

## نصب و راه‌اندازی

### 1) کلون پروژه

```bash
git clone <repo-url>
cd rubika-bot
```

### 2) نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 3) تنظیم فایل پیکربندی
فایل `config.py` را بررسی و تنظیم کنید:

- توکن ربات را وارد کنید
- `WEBHOOK_URL` را به آدرس درست وب‌هوک تغییر دهید
- `ADMIN_CHAT_ID` را اصلاح کنید
- `CHANNEL_LINK` و `CHANNEL_CREATOR` را در صورت نیاز تغییر دهید

### 4) راه‌اندازی وب‌هوک
اگر از حالت وب‌هوک استفاده می‌کنید، فایل `index.php` را روی هاست یا سرور خود قرار دهید و آدرس آن را در `config.py` یا متغیر محیطی `WEBHOOK_URL` ثبت کنید.

### 5) اجرای ربات

```bash
python main.py
```
